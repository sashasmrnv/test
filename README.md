# Telegram Шашки (русские) — бот для группы

Бот для игры в русские шашки прямо в групповом чате Telegram.
Доска рисуется inline-кнопками внутри одного сообщения — игроки ходят, нажимая на клетки.

Написан на **aiogram 2.12**.

## Возможности

- Русские шашки 8×8: простые бьют вперёд и назад, взятие обязательно,
  серия взятий продолжается до конца, дамка ходит и бьёт на любое расстояние.
- Превращение в дамку, в том числе во время серии взятий.
- Открытый вызов: `/play` создаёт партию с кнопкой «Присоединиться».
- Адресный вызов: `/play` в ответ на сообщение игрока или `/play @username` —
  принять партию сможет только указанный соперник.
- Рейтинг игроков по системе Эло, отдельный для каждой группы
  (`/top` — таблица лидеров, `/me` — личная статистика).
- Таймер на ход с предупреждением: за `WARN_BEFORE` секунд до конца бот
  пингует игрока, при просрочке — поражение по времени
  (настраивается через `MOVE_TIME_SECONDS`, по умолчанию 60 сек).
- Подсветка: 🟨 — выбранная шашка, 🟩 — доступные ходы.
- Кнопка «Сдаться», автоматическое определение победы (нет фигур или нет ходов).
- Несколько партий одновременно в одном чате (каждая в своём сообщении).

## Обозначения

| Символ | Значение            |
|--------|---------------------|
| ⚪ / 🤍 | белая шашка / дамка |
| ⚫ / 🖤 | чёрная шашка / дамка |
| ⬛      | пустое игровое поле |
| ⬜      | неигровое поле      |
| 🟨      | выбранная шашка     |
| 🟩      | куда можно пойти    |

## Установка и запуск

Весь бот — в одном файле `checkers_bot.py`.

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Откройте `checkers_bot.py` и впишите токен в начало файла:
   ```python
   BOT_TOKEN = "123456:ваш_токен"
   # при желании поправьте MOVE_TIME_SECONDS и WARN_BEFORE
   ```
4. Запустите:
   ```bash
   python checkers_bot.py
   ```
5. Добавьте бота в группу и напишите `/play`.

> Команды бот видит в группах и без отключения privacy mode
> (сообщения, начинающиеся с `/`, всегда доходят до бота).

> ⚠️ Токен прописан прямо в файле. Не публикуйте файл с реальным токеном
> в открытых репозиториях — это даёт посторонним полный контроль над ботом.

## Как играть

1. Один участник пишет `/play` — появляется приглашение с кнопкой.
   - Чтобы вызвать конкретного игрока, ответьте командой `/play` на его
     сообщение или напишите `/play @username`.
2. Второй участник нажимает «✅ Присоединиться» — начинается партия.
   Создавший игру играет белыми и ходит первым.
3. В свой ход нажмите на свою шашку (🟨), затем на подсвеченную клетку (🟩).
4. Если есть взятие — ходить можно только взятием; серия боя продолжается
   той же шашкой до конца.

## Команды

| Команда                | Действие                                            |
|------------------------|-----------------------------------------------------|
| `/play`                | Открытый вызов на партию                            |
| `/play` (reply) / `/play @user` | Вызвать конкретного соперника              |
| `/top`                 | Таблица лидеров группы (рейтинг Эло)                |
| `/me`                  | Личная статистика: рейтинг, победы, поражения       |

## Рейтинг

Каждая группа ведёт собственный рейтинг Эло (старт — 1000, K = 32).
После партии победитель и проигравший получают пересчитанные очки,
изменение показывается в сообщении о результате. Сдача и поражение
по времени засчитываются как проигрыш. Данные хранятся в `ratings.db` (SQLite).

## Таймер на ход

На каждый ход даётся ограниченное время (`MOVE_TIME_SECONDS`, по умолчанию
60 сек). В классических шашках используется накопительный контроль времени,
но для асинхронного чата удобнее лимит на отдельный ход. За `WARN_BEFORE`
секунд до конца (по умолчанию 10) бот присылает предупреждение с упоминанием
игрока; если он так и не сходил — поражение по времени. Время отсчитывается
заново с началом каждого хода (и на каждом шаге обязательной серии взятий).

## Примечания

- Партии хранятся в памяти процесса — при перезапуске активные игры теряются.
- В серии взятий бьющиеся фигуры снимаются сразу (а не в конце хода);
  для дружеской игры в группе это незаметно, но в редких позициях дамки
  может отличаться от строгого турнірного правила.
